# Project Patterns

Use this reference when the request mentions MusicFlowAI, LaoshiAI, or a similar app demo/social-video workflow.

## MusicFlowAI

Best fit:

- Long educational YouTube walkthroughs.
- SEO-targeted app demos.
- Product-led videos that show how users create, package, and schedule AI music.
- Avatar host plus screen demo.

Useful narrative:

- Start with proof of a finished song/video/content draft.
- Explain that the hard part is not one AI song; it is a repeatable channel workflow.
- Show the full path: channel context -> producer -> song prompt -> generation -> playback -> video settings -> export -> schedule -> monetization/scaling.
- Emphasize that MusicFlowAI keeps the user in one tool and lowers the need to be highly creative from scratch.

Production preferences:

- Target 10-15 minutes for full walkthroughs.
- Use short avatar chunks for hook, transitions, monetization framing, and CTA.
- Use medium desktop capture, often around `1440x900`, framed inside a 16:9 composition.
- Include playback moments so viewers hear or see the generated result.
- Keep overlays minimal and functional: click target, prompt card, status label, output proof.

Common artifacts:

- `series-plan.md`
- `video-XX-production-plan.md`
- `video-XX-two-column-script.html`
- `production-capture-map.md`
- `asset-manifest.md`
- `hyperframes/`
- `renders/`

## LaoshiAI

Best fit:

- App marketing videos.
- Short-form social clips.
- App Store CTA assets.
- Batch transformations of existing TikTok/Shorts-style clips.

Useful narrative:

- Lead with a concrete study pain or student moment.
- Show the app outcome quickly: Smart Notes, flashcards, quizzes, study maps, or Ask AI.
- Keep the CTA direct and visible.

Production preferences:

- For PrayerLock-style batches, use the existing `laoshiai-prayerlock-batch-video` skill instead of rebuilding that workflow.
- For new product demos, use the standard pipeline in this skill.
- For vertical social, preserve source clip audio when required, then add the app promo tail or product demonstration.
- Verify vertical output at `1080x1920` and use a contact sheet before scaling.

## Generic SaaS or App Demo

Best fit:

- Product tutorial.
- Feature launch.
- Onboarding walkthrough.
- Support or education video.

Recommended flow:

1. Proof-first hook.
2. Problem and promise.
3. Step-by-step demo.
4. Output review.
5. Packaging, sharing, or publishing.
6. Recap and CTA.

Keep the viewer oriented with visible UI actions and concise voiceover. Avoid decorative overlays that compete with the app screen.
